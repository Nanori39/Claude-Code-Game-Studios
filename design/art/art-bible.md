## 1. Visual Identity Statement

### One-line visual rule

> **「抽象ボドゲの誠実さに、戦場の生命感を宿す。すべての戦略要素は一目で読める。」**

装飾より情報、派手さより清潔さ、しかし無機質ではなく "ジオラマ" としての世界感を持つ。

### Supporting Principles

#### 1.1 可読性は装飾に勝る (Readability Beats Decoration)
- 道・補給線・陣地境界・駒の所属は **常に・どの距離からも** 区別可能
- 装飾要素（影・ハイライト・パーティクル）は情報伝達を阻害しない範囲のみ
- **Pillar tie**: 「シンプルなルール、深い帰結」「頭脳戦の純粋性」
- **Design test**: 装飾 vs 情報伝達で迷ったら → **情報伝達**

#### 1.2 抽象だが、生きている (Abstract Yet Alive)
- Hive のような完全抽象記号ではなく、駒は "ミニチュアフィギュア" の輪郭を持つ
- 地形は記号ではなく "ジオラマピース" として質感（木・石・水）を僅かに表現
- 派手な細部は避け、シルエットと素材感で生命感を出す
- **Pillar tie**: 「包囲は罠である」（盤面のドラマ性）
- **Design test**: 完全抽象アイコン vs ジオラマ表現 → **ジオラマ表現を控えめに**

#### 1.3 静謐な戦場 (Quiet Battlefield)
- 派手な色彩・強いコントラスト・ネオンは避ける
- 落ち着いた自然色を基調に、緊張感は **構図・情報密度・盤面の歴史（道の蓄積）** で表現
- BGM がなくても成立する視覚的静けさ
- **Pillar tie**: 「道は意図を語る」（盤面そのものが語る）
- **Design test**: ネオン/強調色 vs 自然色基調 → **自然色**

## 2. Mood & Atmosphere

### State-by-state mood targets

| State | Primary Mood | Lighting | Atmosphere Descriptors | Energy |
|---|---|---|---|---|
| **Opening / Setup**（マップ生成・駒配置） | 静かな期待感 | 朝の柔らかい光・低コントラスト・少し冷たい色温度 | 静寂、清潔、未踏、整然、可能性 | Low / 静 |
| **Expansion**（序盤〜中盤、道を伸ばす） | 集中と発見 | 中性的な日中光・均一・影は薄く | 思索的、流動的、開放的、構築、リズム | Medium / 着実 |
| **Skirmish**（陣地境界の競合） | じわじわ高まる緊張 | 影が長くなる午後光・暖色ややシフト | 緊密、かみ合い、計算、駆け引き、針 | Medium-High / 拍動 |
| **Collapse / Climax**（崩壊フェーズ・砦突入） | 静かな絶望 or 希望 | 夕暮れの低照度・赤味のあるアクセント・コントラスト最大 | 切迫、決断、孤立、ドラマ、終焉 | High / 凝縮（派手さではない） |
| **Victory / Defeat** | 余韻 | フェードアウト・モノクロ寄り・盤面が "歴史" として残る | 静謐、物語、敬意、振り返り | Low / 静止 |

### 共通ルール
- **派手な遷移エフェクトは禁止**（Pillar 3: 静謐な戦場）。状態変化はライティングと色温度のシフトで穏やかに表現
- **Collapse フェーズだけ例外的に強い視覚信号**（赤味、彩度上昇、盤面の周辺で僅かなパルス）— ドラマの中心であることを示す
- BGM は控えめ（環境音中心）。視覚で全状態が判別できる必要あり
- 状態遷移は 0.5〜1.5秒 のクロスフェード。瞬時切替は避ける

## 3. Shape Language

### 3.1 駒のシルエット哲学

**ルール**: 駒は **9種すべてが影絵で識別可能** であること。これが「可読性最優先」の駒レベルでの実装。

| 駒 | シルエット特徴 | 読み取りキー |
|---|---|---|
| 狼 | 低く長い、四足獣 | 鋭い耳・尻尾 |
| 虎 | 中型、低姿勢、攻撃的 | 縞シルエット示唆 |
| 鷲 | 翼の広がり、高さ | 翼の輪郭・台座（飛行表現） |
| 猿 | 細身、立ち姿、長い腕 | 上向きシルエット |
| 熊 | 太く重い、立ち姿 | 大きな塊感 |
| 山羊 | 角・斜面感 | 角の特徴形 |
| 人 | 直立人型、武装 | 唯一の人型 |
| 猪 | 太く低い、突進姿勢 | 牙の示唆 |
| 鯨 | 海上、巨大 | 海上限定・他駒の倍以上 |

- **底面台座** で所属陣営（藍 or 朱）を識別
- **サイズスケール** を若干変えて、重さも視覚化（熊・鯨は大きく、狼・鷲は小さめ）

### 3.2 環境ジオメトリ

- **盤面: 正方マス（9×9 / 18×18 / 24×24）** — 仕様書通りの正方グリッドを採用
- **地形タイル**: マス境界より地形タイルの輪郭がやや内側に。グリッド線が常に微妙に見えることで「ここは盤面である」感を保つ
- **地形の幾何**:
  - 平地: 滑らか・低密度の質感
  - 山: 角ばった三角形群、上方向のシルエット
  - 崖: 鋭い直線・段差
  - 川: 流れる曲線、青色アクセント
  - 海: 大きな水域、波の繰り返しパターン
- **角ばった自然 vs 流麗な水流** の対比で、地形の "性質" を視覚化

### 3.3 道（最重要）

- **道は線ではなく、薄いタイルオーバーレイ** として表現
- 駒の所属色のうっすらした路面（藍 or 朱の彩度低めバージョン）
- **道で囲まれた領域は、領域全体に薄い同色グラデーション** を敷くことで陣地化を即座に示す
- 上書きされた道は、新しい所属色に切り替わる（過去の所属はマップ履歴 UI で確認可能）

### 3.4 UI シェイプグラマー

- **直線基調・角丸最小**（ボードゲームの "盤面" に統一）
- 円形は「補給線アイコン」「砦」など限られた特別な意味のみに使用
- 装飾なし、機能的な線とアイコン
- フレーム・パネルは細い枠線のみ（影なし or 極めて控えめ）

### 3.5 Hero shapes vs Supporting shapes

- **Hero shapes（目を引く）**: 砦（最大・特異形）、鯨（巨大・自由位置）、Collapse カウンター（中央UI）
- **Supporting shapes（背景化）**: 平地タイル、グリッド線、UI フレーム
- 駒は中間 — シルエットで個性を持つが、過剰に主張しない

## 4. Color System

### 4.1 Primary Palette

| Color | Hex (suggested) | Role | Why this color |
|---|---|---|---|
| **藍 (Indigo)** | `#2C4F7C` | 陣営A：味方/プレイヤー1 | 落ち着いた知性・冷静な戦略の象徴 |
| **朱 (Vermilion)** | `#C0392B` | 陣営B：相手/プレイヤー2 | 動的・攻撃的だが土色寄り（ネオン回避） |
| **柏 (Tan/Earth)** | `#A8956E` | 平地・基本背景 | 自然色基調、戦場の土 |
| **苔 (Moss)** | `#5C7C44` | 山・林の地形 | 高地特化駒との関連 |
| **石 (Stone Gray)** | `#7D8884` | 崖・岩 | 障害物としての中性色 |
| **水 (Water Blue)** | `#6B98AB` | 川・海 | 陣営藍より明るく、混同しない |
| **白 (Off-white)** | `#F4F1E8` | UI 背景・テキスト・砦上面 | 紙のような自然白 |
| **墨 (Charcoal)** | `#2A2A2A` | テキスト・線・グリッド | 純黒ではなく僅かに茶を含む |

### 4.2 セマンティック色（ゲーム機能）

| Meaning | Color | Backup cue（カラーブラインド対策） |
|---|---|---|
| **陣営A 所属** | 藍 (`#2C4F7C`) | 駒台座の **正方形**、道タイルの **斜線パターン** |
| **陣営B 所属** | 朱 (`#C0392B`) | 駒台座の **円形**、道タイルの **横線パターン** |
| **補給接続中（OK）** | 緑のオーバーレイ (`#5C7C44`) | 連続実線アイコン |
| **補給切断中** | 朱のパルス (`#C0392B` 点滅) | 破断アイコン + 数字（崩壊カウント） |
| **崩壊フェーズ進行中** | 周辺に赤い枠 + 彩度上昇 | 中央 UI に大きな数字 (3→2→1) |
| **勝利マス（敵砦）** | 金色アクセント `#C9A961` | 王冠/旗アイコン |
| **トラップ位置（自分のみ可視）** | 半透明グレー `#7D8884` | アイコン重ね |

### 4.3 UI パレット

- **背景**: 白 (`#F4F1E8`) または墨 (`#2A2A2A`) のダーク/ライトモード両対応推奨
- **アクセント**: 陣営色を控えめに使用（プレイヤー名・スコア表示）
- **テキスト**: 墨基本、補助情報は中間グレー
- **エラー・警告**: 朱（陣営Bと衝突するため、文脈で区別 — UI内では朱は警告のみ、駒所属では台座形状で区別）

### 4.4 カラーブラインド安全性

**最重要対**: 藍 vs 朱（陣営識別）— 青vs赤系は赤緑色覚異常では識別可能だが、青黄色覚異常では難しい
- **必須バックアップ**: 駒台座の形（正方 vs 円形）、道のパターン（斜線 vs 横線）
- **テスト**: モノクロ表示でも陣営が識別可能であること

**緑 vs 朱（補給OK vs 切断）**: 赤緑色覚異常で最も困難
- **必須バックアップ**: 連続線 vs 破断線アイコン、テキスト表示

**カラーブラインドモード（オプション）**: 設定で陣営色を「藍 vs 黄」など別のペアに切り替え可能にする（Tier 1 以降）
